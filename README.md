# Simulador de Actividad para Chrome

**Simulador de actividad** es una extensión de Chrome que simula actividad del usuario en la página web activa para evitar que la sesión se bloquee o cierre por inactividad. Esto es útil para mantener sesiones abiertas automáticamente.

## Características
- Simulación de movimientos del mouse en la página activa.
- Botón de activación y desactivación.
- Interfaz simple y clara.

## Instalación

1. Descarga o clona este repositorio en tu máquina local.
2. Abre Chrome y navega a `chrome://extensions/`.
3. Habilita el **Modo de desarrollador** en la parte superior derecha.
4. Haz clic en **Cargar descomprimida**.
5. Selecciona la carpeta que contiene este proyecto en tu computadora.

## Uso
- Haz clic en el icono de la extensión en la barra de herramientas de Chrome.
- Haz clic en el botón "Activar" para empezar a simular la actividad.
- El botón cambiará a "Desactivar" una vez activada la simulación.
- El estado de la simulación se actualizará en la interfaz.

## Tecnologías utilizadas
- JavaScript
- Chrome Extensions API
- HTML, CSS
